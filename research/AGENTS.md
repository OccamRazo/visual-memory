# Research Directory

- Store surveys, literature evidence, source metadata, and research proposals here. Keep experiments, engineering plans, paper drafts, and presentations in their existing repository directories.
- Organize materials under `YYYY-MM-DD/` using the document's stated survey cutoff or version date. Do not infer dates from file modification times or Git timestamps. Use `undated/` when the date is unknown.
- Keep each survey's report, appendices, and source data together. Add a topic subdirectory only to distinguish independent surveys on the same date; preserve existing `survey_1/` and `survey_2/` groups.
- Use descriptive filenames. Preserve existing names when moving files, and create directories only when needed.
- Maintain `README.md` as the chronological index, with dated entries in ascending order and undated entries last. Update it when adding, moving, or renaming materials.
- Update affected local links and script paths after a move. Preserve external citations and links to historical Git revisions.
- Preserve original reports and evidence. Save substantial revisions as separate dated documents and link their predecessors; do not silently replace earlier conclusions.
