# 内容关联记忆与证据完整性：动机验证实验

日期：2026-09-16。状态：重新规划，尚未执行。承接并取代[9 月 15 日验证方案](task_structured_memory_motivation_validation_2026-09-15.md)作为当前实验入口；历史记录保留。当前区分动机诊断与方法初验，不训练 critic、证据生成器或投射器。

## 1. 主张与验证链条

核心动机：逐条选择记忆可能割裂跨片段的证据依赖。基于对象经历、事件过程和状态变化等内容关联组织记忆，有望在有限预算下，提高未来问题所需证据组合被完整保留并取回的概率。

分别验证以下命题，不能用最后的准确率替代中间测量：

1. **完整性的作用**：以小规模补全实验验证当前回答器能否利用完整证据改善回答，并估计可修复空间；不把“充分证据一般比不充分证据好”作为主要学术命题。
2. **缺口的位置与规模**：检验强基线在编码、保存或取回的哪个阶段丢失证据组合，以及这种缺失有多普遍。
3. **自动内容组织有效（方法初验）**：实际问题未知时，从观测自动建立的内容关联能否指导存取，提高完整证据交付率和答题表现。
4. **任务先验有用**：固定写入算法、模型及其他条件，仅改变构建前的任务先验，能否改善目标任务的证据完整性与答题表现。

先通过小规模实验一验证完整性的实际作用，再通过实验二定位缺口，判断问题是否值得解决；实验三保留原内容关联存取四格，实验四单独验证固定写入器下的任务先验交换。两者不合并为任务×写入×读取网格，也不增加独立的任务证据需求差异诊断。方法初验成功可以支持解决方向，某个实现失败不能单独否定完整性瓶颈或任务适应的动机。

“内容有关联”“组合具有互补性”“组合足以回答某题”分别判断。内容块可以重叠、跨时段，并允许组合或部分读取；不预设固定大块必须整体保存。首轮无需证明每个内容块都是一个充分证据组，也不预设联合训练必要。

## 2. 平台、任务与公平条件

先用 **WorldMM** 完成主验证，再用 **Ego-R1** 检查结论能否迁移。2026-09-16 重新核查了两者[官方 WorldMM 仓库](https://github.com/wgcyeo/WorldMM)和[官方 Ego-R1 仓库](https://github.com/egolife-ai/Ego-R1)，未安装或运行。保留它们原有的多尺度、图索引和多轮工具能力；不能把强基线退化为平铺 top-k 后再比较。REVEAL 类充分性检索可作后续读取对照，不作为首轮启动依赖；没有核实官方实现时不能称为官方复现。

数据沿用 EgoLifeQA 与 Video-MME-long。重点分析对象身份/交接、状态变化、跨事件时序；单事件识别作对照。全局计数、否定和“最后一次”等问题可能要求全历史覆盖，首轮单列，不用几个正例片段冒充充分证明。标记仅凭字幕或常识可答的问题，另报告视觉依赖子集，避免混淆视觉记忆贡献。

建议独立开发约 60 QA；新测试先导约 300 QA，其中 200 题按自然分布抽样、100 题按内容依赖类型富集。富集不得依据某方法的成功或失败选题，两部分分别报告。按共享视频/历史/事件划分数据和统计聚类；同一历史的多题共享一份冻结记忆。300 题不保证显著性，正式规模根据开发阶段的配对差异和有效历史数估算。

共同协议：观察历史 → 固定前端候选 C → 在测试问题、选项和答案不可见时构建 M → 冻结 M → 逐题读取并回答。任务先验来自训练/开发数据或预先声明的部署需求；每题清空临时状态。构建时可访问有限的完整历史，当前不声称在线常数空间写入。

- 固定帧/片段采样、分辨率、事实抽取、存储格式和载荷编码，以及同一平台内的回答器、控制器和输入格式化方式。
- 存储预算 Bs 包含可访问图像/片段、文字、向量、关联索引和全部元数据；共享来源去重。原视频不能通过免费回读绕过预算。
- 读取预算 Br 包含累计检索、验证、重排、视觉工具、调用和重试；最终回答输入预算 Bi 也固定。方法可改变预算内的读取策略，不能增加额度。
- 公布构建计算成本；自动关联抽取提供的信息对照组同样可用，不能只为实验组增加更好的描述或视觉观测。
- 存储选择实验固定的是候选全集和预算，所选内容允许不同；固定内容的读取对照必须使用同一 M。二者不能混称“信息完全相同”。

先在开发集固定一个同时存在存储和读取约束、且有充分组可容纳的工作点，再扩展两个邻近预算。可从候选字节的 10%/25%/50% 中预选，不能按测试收益挑工作点。原生无限制结果只作接入校准，和预算适配结果分开。

### 2.1 简答题为机制验证主评测，原始题型为比较参照

**采用简答题评估主要机制，用独立大模型判断答案正确性。** 目的在于减少选项提示和排除法的影响；简答仍可能依靠先验猜对，不能用正确率替代证据完整性。实验一至四统一采用该协议。

- 原本是简答题的保留；选择题移除选项和选项编号。若题干依赖“下列哪项”等表述，作最小语义改写，保持原问题的对象、时间范围、所问事实和难度目标。去掉选项后仍有歧义或无法形成明确评分标准的题标为不适配，保留原始题型记录并报告数量，不能按模型表现决定去留。
- 保存原题 ID、原题干/选项、简答版本、改写原因、可接受答案及必要事实。题目转换和评分规则在正式方法输出产生前冻结。充分证据针对简答版本重新核验：足以排除选择题干扰项的证据，未必足以支持自由作答。
- 简答轨道的查询规划器、检索器和回答器均不能看到原选项、参考答案及评分事实清单。各方法采用同一简答提示与输出上限，只要求直接回答所问内容，不额外要求长篇解释或推理过程。
- **保留原始题型轨道**，按原基准指标报告，作为与原题设置比较的参照。简答结果明确标记为改编评测，不冒称原 benchmark 官方成绩；预算适配仍需单独标记。两轨尽可能使用同一题目清单和同一冻结记忆，但每题/每轨清空查询状态，禁止跨轨复用答案、检索结果或推理。分别记录轨道成本及适配覆盖率，不能把两种题型的分数直接作方法增益比较。

### 2.2 答案判分与证据核验独立进行

**正确性评判模型的输入**为简答问题、待评答案、经源内容核验的参考答案/可接受替代表述和固定事实评分规则；隐藏方法名称、实验条件、其他方法答案和完整性评分，不提供该方法的检索包，防止因其信息不足而放宽正确性标准。

按语义和必要事实评分，不按字面相似度评分。主要任务指标为“全部必要事实答对且无实质错误/矛盾”的比例；多事实问题补充报告事实级得分，接受同义表达和无害额外描述。事实级得分先按题归一化再平均，避免多事实题自动获得更高权重。完整性指证据是否充分；“全部答对”指答案是否满足题目，二者不混用。

判分保留整体结论（正确/错误/未确定）、逐事实匹配/遗漏/矛盾及简短理由。冻结评判模型版本、提示和解码设置，各答案独立匿名评判；以题目版本、参考/规则版本和预测答案为键去重缓存，保证同题同答同分。若发现有效替代答案或参考缺陷，盲审后统一更新该题标准，并重判所有相关条件，不能只给某个方法放宽规则。

**证据充分性另行核验**：检查实际交付内容能否支持回答所需事实及关系，并核对来源。不能因答案正确反推证据充分，也不能因答错反推证据不足。未确认充分但答对的情况先排查替代路径；无法确认缺口时保留“未确定”，不直接标成猜测。

开发集先校准大模型评分与人工判断的一致性；测试中对匿名问题—答案对随机抽审，并额外审查分歧、未确定和影响方法结论的案例。与第 3 节证据审计可共用样本，但分别记录两类标签。随机审计用于估计误差，定向复核不能替代它；评判不确定项单列并作上下界敏感性分析，不静默删除。LLM 评分是经审计的评估工具，不作为天然真值。

### 2.3 任务适应写入的已知信息与边界

采用“**构建前已知任务族或任务分布，未知具体测试问题**”的设定。任务说明及类别体系来自训练/开发数据或预先声明的部署需求，例如对象身份/交接、状态变化、事件时序；不得包含测试问题、答案、选项、特定对象/时间提示或该题的充分证据组。

任务条件只改变写入时的选择偏好，所有条件的候选观测、表示、来源和资源相同。先保持内容抽取固定，检验任务先验对选择性保存的作用；这不能直接证明任务适应编码或更好的视觉抽取有效。读取阶段自然可以看到当前问题，但写入对照中读取器、回答器及其提示固定，不额外提供因写入条件而变化的任务提示。

不同任务先验下的记忆是相互独立的部署条件，每个条件只允许一份 Bs 预算的记忆；不能保存多份任务记忆，再看到问题后免费切换。先验在问题揭示前指定、记忆冻结，一份记忆回答该条件预先登记的全部问题。

## 3. 完整性的标注与测量

完整性的操作定义：对于一个问题，现有内容可以支持至少一组足以回答该问题的事实及其关系。允许替代证据、隐含但可恢复的关系以及多个充分路径；不要求所有相关片段到齐，也不要求某条显式关系边存在。

标注采用“自动提名 → 独立核验 → 人工抽审”：

1. 利用已有时间标注、描述和强模型定位候选来源，输出必要事实、来源 ID、关系、可能的替代路径；时间标签只用于定位。
2. 独立核验者检查实际帧/片段是否支持这些事实，以及组合能否支持回答。独立重答时不展示参考答案或提名者的推理，输出后再核对参考。
3. 对组合做局部替换或删减，辅助辨认关键缺口；“删掉就答错”仅是模型敏感性证据，不自动证明全局必要性。
4. 测试先导可随机抽审约 60 题，并额外审查分歧、自动方法新增收益以及未匹配已知路径但答对的例子。随机审计与定向审计分开，用前者估计标签误差；配对干预的所有输入包做盲审。

标签分“已确认充分”“已确认缺口”“未确定”。对未匹配已知充分路径的输入，不能直接断言不存在其他路径。自动评估结果明确称代理指标；主要机制结论在独立审计子集上复核。若随机审计误差或未确定比例过高，扩充审计或改善标注，再解释方法差异。

| 指标 | 含义与用途 |
| --- | --- |
| C 完整率 | 固定前端候选中是否可恢复充分证据；定位采样/编码限制 |
| S 存储完整率 | 冻结 M 中是否保有至少一组已核验充分证据 |
| D 交付完整率 | 实际回答上下文中是否交付至少一组已核验充分证据；主机制指标 |
| R 条件取回率 | 在 M 已完整、输入预算可行的题上，读取能否交付完整证据 |
| A 简答全部正确率 | 按第 2.2 节由大模型统一判分并人工抽审；全部必要事实正确且无实质错误/矛盾，主任务指标 |
| F 简答事实级得分 | 多事实题逐事实计分，先按题归一化再平均；辅助辨认局部改善，不能取代 A |
| A_orig 原始题型成绩 | 按原基准协议单列报告，保留公开比较接口；不与简答 A 混合 |
| J 有充分证据且答对 | D 与简答 A 同时成立的比例；补充 A，不能取代 A |

主表保留预先登记的全体分母，同时列出可核验率、输入预算可行率及条件指标。未确定样本不在主表中被悄悄剔除；已知路径覆盖只能作为实际充分率的保守估计，需配套报告未确定比例。各方法 S 不同导致 R 的条件样本不同，跨方法直接比较 R 有选择偏差；应另在共同可行子集比较，并以同分母 D 为主。

多轮系统记录全部合法证据流。最终上下文包括真正传给回答器的中间消息和工具摘要；仅曾被其他工具看见、却未传入回答上下文的源证据不算交付。摘要只计入其实际承载、且能追溯验证的事实，不用合法引用 ID 冒充语义支持。

## 4. 实验一：完整性的作用——小规模证据补全

本步骤定位为小规模诊断：估计强基线的证据缺口有多少能被当前回答器转化为收益，不以证明抽象的“完整优于不完整”为主贡献。从预登记样本中按证据可见性和干预可构造性选择配对题，选择不依赖回答模型是否答对。先比较原输入与完整性修复；若需要区分补全作用与普通相关信息增益，再启用相关补充及无关替换对照。对同一简答问题、同一回答器和同一输入预算，固定共同上下文与替换位置，构造：

本步骤只需运行小样本基线并核验配对输入，不要求先完成全体样本的阶段缺口归因。重点先回答“完整证据能否带来实际答题收益”；来源记录保留供实验二复用。

| 条件 | 替换进去的内容 |
| --- | --- |
| 原输入 | 强基线实际交付内容 |
| 完整性修复 | 恰好补上已核验缺口，使至少一条充分路径闭合 |
| 普通相关补充（归因扩展） | 同量、同模态、相近质量的相关内容，但不补齐缺口 |
| 无关替换（归因扩展） | 同量干扰内容，用于估计普通上下文扰动 |

所有条件满足相同预算上限，尽量匹配实际视觉 token、文本长度、来源粒度和位置。用替换而非免费追加；无法匹配或补齐的题记录为不可构造，不强造对照。相关补充条件由独立核验确认没有形成替代充分路径。固定输入顺序规则、提示、解码和评分。

**基础诊断比较“完整性修复 − 原输入”的简答正确率差**，同时报告被修复和新增答错的题数。启用归因扩展时，预先登记“完整性修复 − 普通相关补充”的比较，可在完整包上反向替换关键桥接证据。控制条件仍无法消除所有语义差异，因此只能辅助分析特定证据补全的作用，不宣称已隔离一个与内容无关的抽象完整性变量。

将修复来源分成两类：缺口可以从当前 M 补齐，或必须从 C 中恢复未保存的内容。前者反映读取改进空间，后者提示保存损失。它们都是使用题目及诊断证据的特权干预，不是合法查询前写入器，也不是性能保证或同搜索成本的方法。

若完整包仍无法被固定模型利用，先检查可见性、消费者和评分，不根据模型成功重新筛掉失败题。“证据完整时更容易答对”的观察相关性不能单独证明机制；核心方法证据仍来自实验三的自动内容组织、完整性交付与简答表现的共同变化。

## 5. 实验二：强基线的证据在哪里缺失

在 WorldMM 和后续 Ego-R1 的预算版本上，逐题核验 C、M 和最终上下文，统计：

- 原始视频支持答案，但 C 已丢失关键事实：前端/编码限制。
- C 存在充分路径，M 缺失：保存阶段的缺口。
- M 有可容纳的充分路径，最终上下文不完整：取回缺口。
- 最终上下文完整但仍答错：消费者或评分限制。

无法排除替代路径时单列未确定，不强行归因。输入预算根本装不下充分证据的情况另列。分阶段路径覆盖与故障核验是诊断，不把各阶段 oracle 差值相加当作严格因果分解。

同时报告单条事实召回与 D：关注“已取到多数相关事实、却缺少衔接证据”的现象，但不预设一定普遍。自然抽样集用于估计出现频率，富集集用于分析哪些任务更依赖组合。仍使用预登记样本及原始分母，不仅分析实验一中补全有效的题，避免把修复成功率误作总体缺口分布。

输出：每个基线一张阶段缺口表，按任务类型细分；展示少量有源证据的成功和失败例子。

## 6. 实验三（方法初验）：自动内容关联能否改善完整性

恢复原来的内容关联存取四格，验证一种解决方向的可行性，不作为前述动机成立的必要前提。所有组采用相同的任务先验与任务信息条件，本步骤不交换任务先验。

在相同 C 上构建内容组织：从观测自动关联同一对象的经历、事件的参与者与前后步骤、状态变化及其源证据，允许小组重叠。实际测试问题、答案和人工充分组均不可见。关联有置信度和来源；不把模型臆测的因果边当作观测事实。

首版采用规则或现有模型抽取，不训练新网络。选择规则在开发集冻结，以内容链的覆盖、冗余及新增存储成本为依据；检索在命中一个条目后，可根据当前问题沿已有内容关联补取互补来源。内容块允许拆分和组合，不无条件把整块塞进上下文。

W0 为原基线的预算适配保存，R0 为原生读取。若原框架无预算 writer，在开发集选择强逐条评分加多样性/覆盖策略，并明确其适配身份。W1 按内容关联评估组合的保存价值，R1 在原生检索上进行关联补取和集合重排。保留原存取四格：

| 条件 | 保存 | 读取 | 回答的问题 |
| --- | --- | --- | --- |
| B00 | W0 | R0 | 强预算基线 |
| B10 | W1 | R0 | 内容组织指导保存是否提高 S，并改善 D/A |
| B01 | W0 | R1 | 同一冻结 M 下，关联补取是否提高 D/A |
| B11 | W1 | R1 | 内容组织贯穿存取是否进一步改善完整性和答题 |

B00/B01 共用完全相同的 M；B10/B11 也共用同一 M。各组均可获得相同的基础事实与内容描述；实验变量是如何利用它们组织、选择和读取。实验组新增结构存储开销计入预算。最终仅以统一格式呈现选中的源内容及公共元数据，不增加专属推理提示、金标关系或更密集帧，避免把投射变化混入本轮结论。

**必需对照**：在 B11 的选择和读取框架中，用固定时间分块、语义相似分组替换对象/事件内容关联，分别匹配组大小、预算与搜索额度，尽可能匹配重叠度；公布无法同时匹配的属性。这排除“只因一次取了更多条”或“任意分块都同样有效”的解释。围绕对象和事件组织本身就是本研究对象，不能把它们笼统归为应被排除的“通用结构”。

附加固定内容对照：在同一 M 上保留全部事实，仅改用不同关联路由，测 R0/R1；可作新增关联的受约束打乱诊断，但打乱可能产生异常输入，不能单独作为主证据。无需首次就比较图、文本和 latent 形式。

## 7. 实验四：固定写入器，交换任务先验

沿用此前任务条件交换的设计，单独回答“预先知道下游任务需求是否有助于写入”。**固定写入器指固定算法、模型参数与选择流程；写出的记忆内容允许随任务先验变化。** 本步骤不比较逐条与组合算法，也不切换读取器，不依赖实验三的方法先取得正结果。

在同一段历史和同一候选全集上，使用同一个固定的基线预算写入器，仅改变构建前的任务说明或任务权重。若基线没有该接口，用统一的逐条任务相关评分加覆盖策略作为预算适配探针，在开发集冻结；不要求引入新的内容链方法。选择流程、观测与表示、模型、存储预算、构建调用及调参预算相同，任务说明粒度尽量匹配并记录差异。

| 条件 | 写入时的任务先验 | 用途 |
| --- | --- | --- |
| T0 通用 | 预先固定的各任务混合分布 | 强通用写入参照 |
| T+ 匹配 | 预先指定的目标任务族/分布 | 检验目标任务上的适应收益 |
| T− 错配 | 另一任务族，按预登记规则轮换 | 检验任务先验的特异性 |

通用条件在同样开发数据和调参预算上校准，不用故意弱化的空提示；错配标签不根据测试结果选择。任务先验来自第 2.3 节的部署设定，不能由具体测试题反推。每种条件在问题公开前构建并冻结一份记忆，不保存多份记忆后按题免费切换。

三组使用相同读取器 R0、回答器、输入格式、读取预算和简答评分协议。每组冻结记忆回答同一批问题，报告 S、D 和简答 A；有多任务覆盖时展示“写入先验×评测任务”交叉结果。**同一任务列内、同一批问题做配对比较**，不把不同任务难度造成的对角线高分当作适应收益。样本与任务分类提前冻结，报告有效历史数及任务题数，不按方法收益选题。

主要比较为目标任务上的 **T+−T0**；**T+−T−** 为辅助比较。匹配优于通用且 S/D/A 同向改善，支持任务先验用于受限写入的价值；若只提高 S，则只支持保存完整性改善。匹配只优于错配、不优于通用，说明错误先验可能有害，尚不能证明任务适应优于通用写入。

同时报告目标任务收益、非目标任务损失及预先声明任务分布下的总体效用，不能事后挑分布掩盖损失。如果某个先验对所有任务都更好，不能仅据此认定任务特异性。固定探针没有收益也不能直接否定所有任务适应方法。

本步骤先在一个平台、一个预算进行通用/匹配/错配三组比较，不与实验三四格相乘。原有“同历史任务证据需求差异”的独立诊断不恢复；需要的任务分类和分组统计仅服务本步骤的公平比较。

## 8. 统计、结论边界与下一步

以原始视频/相关历史为簇作配对置信区间。实验一报告小规模补全的答题收益和可修复空间，实验二报告阶段缺口及其规模。实验三的主要比较为相同任务先验下 B11 对 B00；实验四的主要比较为固定写入器下目标任务上的 T+ 对 T0，分别检验 S、D 和简答全部正确率 A。F 为辅助指标，原题型 A_orig 单列。单阶段增量、普通分块、交互和任务错配为预先声明的次级比较；处理多重比较，不在测试集挑最佳基线。所有简答条件遵守第 2.2 节相同的判分、去重和审计协议。

| 观察结果 | 可支持的结论 |
| --- | --- |
| 补全修复明显，但自动内容组织无收益 | 存在可修复的证据缺口；当前自动组织/存取实现未利用这部分空间 |
| B11 同时改善 D 与 A，配对补全也有效 | 支持“内容关联有助于交付充分证据，并带来任务收益”；仍需排查共同改变的因素 |
| 只改善 D，A 无改善 | 只支持完整性交付改善，尚未兑现答题收益 |
| 只改善 A，D 无改善 | 可能来自聚焦、噪声或测量遗漏，不能声称完整性机制已验证 |
| B01 已获得全部收益 | 当前证据支持关联读取；没有证明改变保存的额外价值 |
| 内容关联不优于时间/相似分组 | 尚不能证明内容依赖组织的独立价值 |
| T+ 优于 T0 且 S/D/A 同向改善 | 支持固定写入器下任务先验的价值；不直接证明任务适应与内容组合的交互 |
| 匹配先验只优于错配、不优于通用 | 错配先验有害，尚未支持优于通用记忆 |
| 缺口少、补全收益小且区间足够窄 | 当前任务/预算对该动机支持较弱；宽区间只能判不确定 |

B11 同时启用两个模块不等于联合训练。若主线成立，再用同一模块、监督和搜索预算比较分阶段优化与端到端完整性交付目标；此时才决定是否引入 selector/critic。动机验证不以正交互或某个任意准确率阈值作为先验成功要求。

执行顺序：冻结简答改写、任务分类/先验、参考事实和评判规则，在独立开发集完成可见性/标注/判分校准 → 实验一：小规模补全验证完整性的作用 → 实验二：定位阶段缺口及其规模 → 实验三：原存取四格及分块对照 → 实验四：固定写入器的通用/匹配/错配先验 → Ego-R1 和邻近预算，并完成原题型参照评测。实验三和四可以独立实施，不将某个自动实现通过设为动机成立的前提。

规模分别估算：实验三每个预算为四个主体条件，实验四每个固定目标任务设定为三个先验条件，均不包含辅助对照、原题型和评分成本。只有模型、输入、记忆、配置与协议完全一致时才复用已有条件结果；每题每条件清空查询状态，不能跨条件传递证据。先在一个平台/预算 profiling，再分配扩展资源，不沿用合并版本的六条件成本估算。

最终按四步分别报告：**完整证据能否改善回答；完整性在哪个阶段丢失；内容关联存取是否有效；固定写入器下任务先验是否有用。** 简答事实级 F 和原题型 A_orig 分列，报告改写覆盖、评分审计、正负结果、未知比例、真实资源和适配范围。

沿用[9 月 7 日失败审计](../../experiments/EXP-20260907-egvqa-failure-audit/analysis.md)的教训：时间覆盖不等于语义完整，完整包不保证模型答对，同答案必须同评分。本轮仅完成设计和入口核查，未运行模型或新实验。
