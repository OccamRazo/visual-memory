## 效率与失败

暂停账本共 3,418 次 API 尝试，其中 1,981 次失败；已返回用量 51,467,073 输入 token、11,259,054 输出 token，共 62,726,127 token。失败类型次数为：

- `APIConnectionError`：1886 次。
- `APITimeoutError`：47 次。
- `ValueError`：18 次。
- `RemoteProtocolError`：18 次。
- `ReadTimeout`：8 次。
- `APIError`：4 次。

631 道题的最终失败发生在定位 API 阶段。连接失败占多数，说明后期扩展处理数主要增加失败记录，没有转化为验证产出。模型判定还需纠正评分事实过宽/过严、章节边界串入和缺失实体被推断等问题；多轮源核验与删组调用叠加，增加了单题成本。没有测得这些环节各自的因果贡献，不将全部低效率归因于模型或网络。

已返回用量不含未返回 usage 的请求及本 Codex 会话，提供方实际费用未知。暂停后未测试或修复网络，未重试失败题，未继续人工/AI 源复核。若将来恢复，需先重新决定方法与失败停止规则；本记录不是恢复授权。

## 结果边界

11 题为 AI 源复核诊断样本，不是人工金标、随机测试集或全视频最小证据集的证明。确认标准没有因数量不足而放宽。原 60 题与本轮结果分别保存，不能直接累加。全部 900 题已被题目级筛选查看；本轮尝试对应视频按保守规则计入接触排除清单，即使请求失败也不据此宣称未接触。

[源完整性核验](validation.json)与[交付检查](delivery_checks.json)只覆盖已确认部分。浏览器视频实际播放未测试；逐帧连续观看和人工校准未运行；四步存取方法实验未运行。
