盲观察的设计错误：`source_header()`隐藏了options与reference_answer，然而MCQ题中的选项常属于问题内容。隐藏正确答案标记是必要的，隐藏题目选项并不能保证更独立，反而可能使题意残缺。763-1是直接证例，634-2同时还有范围判断问题。

准入逻辑问题：同一个`source_unresolved`混合了真缺口、参考冲突、审核自相矛盾和题目输入不完整；并且只要任一阶段`missing_zh`非空就阻断，没有区分必要缺口、附带观察和后续已解决项。完整门控重放及实际请求字段见[9题审计JSON](terminal_source_unresolved_audit.json)。

## 当前结论与修复优先级

1. 先修确定的实现问题：重叠窗口来源映射、保留题目选项、点证据表示、具体可定位的错误消息，并区分输出校验失败与连接错误。
2. 再修证据接口：不连续来源保持分段，允许审核提出新来源/边界并重新核验，校验分组数量与联合需求一致；必要缺口与非必要备注分开。
3. 只对仍有真实缺口的题补片段：人物身份上下文、比赛比较范围、节目序号、敲鼓及缺失的历史事件；对参考冲突另行审查。
