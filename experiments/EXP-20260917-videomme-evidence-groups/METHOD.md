# 时间证据组处理方法

对象是冻结的 60 道 Video-MME 题。原题、参考答案及评分事实不变；划分的是已收集源证据的时间范围，不是按帧计数，也不是穷举整部视频的每个镜头。

一组对应一个连续活动：同一对象的制作、同一场对话、同一案件、同一独立表演或明确的专题讲解。动作步骤、视角切换、不同评分事实和检索窗口之间的空隙均不自动产生新组。不同训练日、独立节目、不同案件、插入其他主题后再次出现的内容可以分组。相邻教学章节的粒度若无法稳定判断，标记存疑，不强行纳入多组统计。

|步骤|输入|处理|输出|
|---|---|---|---|
|1 冻结来源|原 60 题 JSONL、原证据包、原字幕压缩包、视频清单|核对原包哈希；统一字幕 ID；保留原时间戳与帧 PTS|`input_manifest.json`、`sources/`|
|2 提议分组|问题、评分事实、完整原字幕、原引用帧及 6 张确定性概览帧|API 按连续活动给出范围、原始锚点、边界理由和事实归属|`calls/*/propose/`|
|3 投射原证据|组范围、原视频、原帧/字幕|校验引用；补抽边界及组内帧；原引用帧不设数量上限|`packages/`、`frames/`、`sheets/`|
|4 分组审计|核心范围及前后各 3 秒上下文、原帧/字幕、评分事实|独立 API 调用检查连续性、过度拆分/合并、完整源支持；自动最多 3 轮|逐组检查、支持集合、修订记录|
|5 删组核验|只保留待测组的核心原帧及完整落在核心内的原字幕、问题、评分事实|先测全组；从支持组合出发逐组删除；每个最终保留组均有删除后失败的记录|`subset_validation`|
|6 会话复查|各题原图、原字幕、自动审计与删组结果|Codex 检查源依据；针对问题冻结修订输入并重跑；补测有源依据的替代组|`reviews/`、`group_overrides/`、`evaluation_notes/`|
|7 校验与导出|全部 60 题结果和复查记录|检验区间/引用、原帧哈希、原字幕归档、原题未变、删组实际载荷；统一导出|`final/` 与仓库摘要|

步骤 2、4、5 使用同一 API 模型的不同调用；步骤 6 是本 Codex 会话的 AI 源检查，**没有人工金标或盲审**。评分事实对核验器可见，因而这些是证据审计，不是回答模型的无答案测试。

**边界约束。** `start_s/end_s` 是核心取证范围；`review_start_s/review_end_s` 只用于查看上下文。它们不宣称逐帧确定动作或场景真实起止。原字幕可能滚动重叠，程序默认合并重叠/相接范围；明确独立章节被误合并时，将核心缩回各章节，跨界字幕仍留在上下文。原分组、失败调用和修订原因全部保留。具体冻结修订见 `group_overrides/`、`adjudication_rules.json`；语义澄清见 `evaluation_notes/`。

**取帧约束。** 有视觉锚点的组在起止处各取 −2/0/+2 秒以及组内 1/4、1/2、3/4 位置；无视觉锚点的字幕组取首、中、尾三帧。审计/删组保留原锚点、新抽帧及至多 4 张确定性原上下文帧。新增图片取解码后实际 PTS，JPEG 质量 94、最长边 1024。这是稀疏视觉核查，不保证覆盖所有短暂动作；取样不足或实体关系不清必须显式标记。

**删组约束。** 被删组的原文、图片、标签、描述、旧结论均不发送；只给保留组源证据及待核验的评分事实。空集合按无证据判失败，不让模型凭常识猜测。跨越核心边界的字幕不会作为保留组证据。导出器直接比对已记录的实际请求，而不只检查理论流程。

**计数解释。** `candidate_group_count` 是当前候选分组数；`validated_irreducible_group_count` 只对通过会话复核的题赋值。后者是当前所给证据及核验器下的一个“不可再删集合”，不是全视频最少组数；局部贪心可能漏掉其他替代集合。669-1 的原两组方案因此在复查后补测 G04，改为一组，完整过程保留。原视频存在更好的其他证据仍有可能。

**存疑处理。** 不改写原题、不静默删除、不为凑足 60 个“通过”标签补抽。全 60 题都有分组，存疑题的可靠必要组数字段为 null，原因见复查记录。阶段命名为 `needs_segmentation_review` 的结果也可能是人物身份/事实未完整支持，最终必须读具体原因，不能只读自动状态名。

/home/baorui/projects/WorldMM/.venv/bin/python experiments/EXP-20260917-videomme-evidence-groups/code/export.py

补测一个复查发现的替代集合使用 `refine_subset.py QID --groups Gxx --reason '源复查理由'`。该程序归档原结果后追加独立源测试。已有复查记录的题默认拒绝改动，避免统计与版本错配。

**重放与重跑。** `export.py` 从冻结结果和复查记录离线重建 JSONL、逐组包与浏览页，无须 API 凭据。原请求、响应、提示、代码快照、源文件哈希及所有人工式 AI 复裁输入均保留，因此可以重放这次结果；全新 API 调用有随机性，不能承诺重新调用后组界和判定完全一致。需要新实验时应复制协议并指定新输出目录，不能清空本次 `results/` 冒充同一次运行。

逐组包包含原视频路径、起止时间、实际帧引用和原字幕。浏览页直接定位播放原视频相应区间；未批量另存 MP4 副本。用于后续模型实验时，读取 `group_packages/` 的原始证据；含参考答案及解释的总表只供标注审计使用。
